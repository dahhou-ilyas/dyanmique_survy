# Changesets

Ce dossier pilote le versionnage du package.

- `pnpm changeset` — décrire une modification et son niveau (patch / minor / major).
- `pnpm version` — applique les notes en attente : versions et CHANGELOG.
- `pnpm release` — construit puis publie.

Le bac à sable (`playground`) est ignoré : il n'est pas publié.
